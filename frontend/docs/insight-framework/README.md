# ELFIS Insight Framework V1

**Phase F1.2.5** · Capacité plateforme transversale de **présentation**  
**Statut :** livré (fondation) — consommé par F1.3 Live Document ; **F1.4 non démarré**

## Objectif

Manière officielle de présenter analyses, alertes, recommandations, explications, opportunités et confirmations — **sans** nouveau moteur IA, **sans** modifier Aura, **sans** inventer données / confiance / sources.

- Contrat `Insight` produit-agnostique (indépendant des Pilots)
- Composants de présentation (Card, Inline, Banner, Toast, List…)
- Mappers depuis données **existantes** (FCC, Composer validation, Health)
- Widgets = containers ; Insights = contenu intelligent présenté
