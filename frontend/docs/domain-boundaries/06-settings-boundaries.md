# 06 — Frontières paramètres

| Scope | Contenu | Route |
|-------|---------|-------|
| ELFIS | Compte, organisation, membres, permissions, communications, abonnements, intégrations | `/platform/settings`, surfaces `/platform/*` |
| Finance | Numérotation, TVA, OCR, modèles envoi facture, journaux métier | `/settings` |
| Commercial | Pipeline, règles, priorités, modèles propositions | `/sales/settings` |

Chaque domaine n’expose que ses paramètres métier dans sa sidebar.
