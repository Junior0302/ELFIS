# 06 — Design system

## Tokens FCC (`fcc.css`)

| Token | Usage |
|---|---|
| `--fcc-radius` / `--fcc-radius-sm` | Coins cartes / chips |
| `--fcc-shadow` / `--fcc-shadow-hover` | Élévation discrète |
| `--fcc-gap` / `--fcc-section-gap` | Espacements |
| `--ps-navy` / `--ps-accent` / `--ps-surface` | Identité produit |

## Widget Framework

- Radius ~0.85rem, ombres allégées, focus-within accent
- Chart body plus haut (héros)
- Transitions hover discrètes ; reduced-motion off

## Interdits design

- Purple-on-white / indigo gradients
- Glow néon, pills massives, multi-ombres lourdes
- Cartes dans le header
- Chiffres maquette inventés
