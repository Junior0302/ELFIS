# 06 — Page header (contrat Vague 2)

**Non implémenté Vague 1** — cible pour revue.

## Contrat cible

| Slot | Contenu |
|------|---------|
| Title | H1 display (`--font-display`) |
| Subtitle | 1 phrase muted |
| Actions | 1–3 CTA alignés droite (accent Pilot) |
| Breadcrumb | Optionnel, sous title |
| Meta | Badges / période — hors hero marketing |

Réutiliser / étendre `design-system` `PageHeader` ; paddings via `PlatformPageContainer`.  
Pas de cards dans le header.
