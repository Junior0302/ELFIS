# 14 — Focus Responsive

## Desktop (≥1100px)

- Header 3 colonnes
- Workspace 66% / 34%
- Preview sticky hauteur panneau
- Hauteur `calc(100vh - topbar)`

## Laptop / tablette (≤1100px)

- Header empilé
- Workspace 1 colonne
- Preview max ~42vh
- Toggle aperçu conservé

## Mobile (≤720px)

- Padding réduit
- Hauteur auto / min viewport
- Preview collapsible
- Pop-in type (Documents) inchangé (F1.3.1)

## Style pass

Navy / accent Compta, ombres légères, sections blanches sur fond gris très léger — crédible, pas design final.
