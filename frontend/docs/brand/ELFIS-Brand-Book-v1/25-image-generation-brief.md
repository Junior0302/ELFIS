# 25 — Image Generation Brief

**Phase :** B0.5 (brief) → entrée **B0.6 — Visual Concept Generation**  
**Usage :** prompt / brief directement actionnable (designer ou générateur d’images).  
**Rappel :** ce document ne contient **aucune image** ; B0.5 ne produit aucun asset.

---

## 1 — Objectif B0.6

Produire les **premières propositions graphiques** (concepts) pour :

- Pilot Mark (explorations grille)  
- Logos / lockups (ELFIS Core, ComptaPilot, SalesPilot, DocPilot)  
- Landing Page  
- Launcher  
- Platform Shell  
- Mockups, illustrations, dashboards, goodies  

**≠** assets runtime officiels fusionnés dans le produit (validation Brand puis phase SVG ultérieure).

---

## 2 — Master prompt (base)

Copier-coller et adapter :

```
Brand: ELFIS Core — B2B connected ecosystem platform (not a single app)
Creative direction: Connected Ecosystem — premium, calm, clear, trustworthy
Emotions (priority): trust, intelligence, fluidity, connection, performance, simplicity, modern, premium
Visual language: geometric minimal, generous whitespace, strong hierarchy,
soft medium corner radii, light functional shadows, no neon glow, no blobs,
no glassmorphism everywhere, no purple mesh gradients
Symbol: ONE abstract Pilot Mark about connecting business domains (nodes/links),
monochrome master, grid 8x8, stroke consistent, NOT a calculator, NOT a document icon,
NOT a lightning bolt, NOT a robot, NOT a mascot
Wordmarks exact: "ELFIS Core" | "ComptaPilot" | "SalesPilot" | "DocPilot"
Product lockups may include signature: "by ELFIS Core"
Illustration style: elfis_connected_minimal — flat geometric, thin strokes,
2-4 abstract characters max, orderly workspace, multi-screen operations,
data flowing abstractly between modules, no stock handshake, no person pointing at chart
UI: platform navy #0B1F3A, accent #3D7EFF; product primaries:
Compta #0B3D2E, Sales #1D4ED8, Doc #C2410C
Layout: one focal point; hero without cards/stats/sticker badges
Motion feel (if storyboard): short ease-out, mark stays stable when switching products
```

---

## 3 — Prompts spécialisés

### Pilot Mark concepts (×3)

```
Abstract monochrome logo mark on 8x8 grid, connected ecosystem metaphor,
minimal geometric strokes, works at 16px and large size, corporate SaaS,
no letters inside mark, no pictogram of finance/sales/docs
```

### Landing hero

```
ELFIS Core landing hero, full-bleed calm navy/soft neutral atmosphere,
Pilot Mark + wordmark "ELFIS Core", one headline, one short sentence, one CTA,
connected ecosystem vibe, generous whitespace, no cards in hero, no stock photo clichés
```

### Launcher

```
App launcher panel for business suite, grid of app tiles each with SAME mark
recolored (green, blue, orange, navy) + CamelCase names ComptaPilot SalesPilot DocPilot,
premium minimal UI, soft surfaces, connection motif subtle
```

### Platform Shell

```
B2B platform shell UI, navy sidebar/topbar, ELFIS Core mark, clean workspace,
light borders, medium radii, no heavy shadows, professional dashboard chrome empty/calm
```

### Product mockup (ex. SalesPilot)

```
SalesPilot product shell, primary blue #1D4ED8, same Pilot Mark tinted blue,
wordmark SalesPilot, optional "by ELFIS Core", CRM pipeline UI clean,
connected ecosystem family look, not a generic Salesforce clone screenshot
```

### Illustration scène

```
elfis_connected_minimal illustration, flat geometric, abstract team at multi-screens,
subtle connection lines, navy and one product accent, no handshake, no rising chart stock pose
```

### Dashboard

```
Clean analytics dashboard UI in ELFIS visual DNA, one product primary for series colors,
neutral axes, spacious cards as interaction containers, mark in topbar
```

### Goodies

```
Premium merch mockup, monochrome ELFIS Pilot Mark embossed or printed,
matte navy t-shirt or card, minimal typography "ELFIS Core", no loud prints
```

## 4 — Checklist cohérence avant d’accepter un rendu

- [ ] Une seule logique de Mark (connexion)  
- [ ] Palette Brand Book uniquement  
- [ ] Pas de cliché stock (chart pose, handshake)  
- [ ] Hero sans surcharge  
- [ ] Pilot différenciés par couleur + wordmark seulement  
- [ ] Ambiance Connected Ecosystem (famille), pas outil isolé  
- [ ] Émotions : confiance & clarté d’abord  

Échec → régénérer avec master prompt + contrainte manquante en négatif :

```
Avoid: neon, blobs, purple gradients, 3D plastic, mascot, robot, handshake,
person pointing at chart, multiple different logos, glowing edges, crowded hero
```
