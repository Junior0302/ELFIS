# 16 — Creative Direction A — Minimal Tech

**Phase :** B0.4 — Creative Exploration  
**Code :** `DIR-A`  
**Inspirations (tonalité, pas copie) :** Stripe · Linear · Notion · Vercel  
**Statut :** exploration — **aucun logo final choisi**, aucun SVG/PNG.

Conforme à B0.1 / B0.2 / B0.3 : Pilot Mark unique, palette figée, Wordmark System, lockups nommés, Design DNA.

---

## 1 — Philosophie

ELFIS comme **outil premium ultra-lisible** : chaque pixel sert une fonction.  
La plateforme disparaît derrière la clarté. Le vide est une preuve de maîtrise, pas un manque.

Narratif : *« Une plateforme si claire qu’on oublie l’interface. »*

---

## 2 — Personnalité

| Trait | Intensité |
|-------|-----------|
| Minimal | Très fort |
| Technique | Fort |
| Chaleureux | Faible |
| Institutionnel | Moyen-faible |
| Expressif | Faible |

Voix : courte, précise, sans superlatifs marketing.

---

## 3 — Émotion

Calme · contrôle · élégance froide · confiance « craft ».

---

## 4 — Type de clients

- Scale-ups tech / SaaS  
- Directions financières / ops qui valorisent l’UX moderne  
- Équipes produit habituées aux outils Linear / Notion  

Moins prioritaire : grands comptes très « corporate brochure » sans sensibilisation design.

---

## 5 — Palette (application — couleurs Brand Book inchangées)

| Usage | Règle DIR-A |
|-------|-------------|
| Fonds | Neutres très clairs ou navy profond ; **peu de secondary saturée** |
| Primary produit | Utilisée avec parcimonie (CTA, Mark, item actif) |
| Accents | Discrets ; un seul accent visible à la fois |
| Surfaces | Presque monochromes ; secondary en teinte à 4–8 % |

HEX : inchangés ([05](./05-palette-officielle.md)).

---

## 6 — Composition

- Grilles larges, colonnes aérées  
- Un point focal par viewport (Mark ou headline, pas les deux en compétition)  
- Peu de traits décoratifs ; séparateurs 1 px neutres  
- Cartes : ombre minimale ou bordure seule  

---

## 7 — Hiérarchie

1. Wordmark / Mark (sobre)  
2. Headline unique  
3. CTA unique  
4. Corps  
5. Méta  

Le Mark est **discret mais impeccable** — jamais un hero « écosystème » chargé.

---

## 8 — Animation

- Fade / translate courts (120–200 ms)  
- Pas de morphing Mark  
- Hover : opacité / underline, pas de scale agressif  
- `prefers-reduced-motion` : coupe tout sauf états essentiels  

Motif dominant : **apparition**, pas « connexion » spectaculaire.

---

## 9 — Surfaces

### Landing

Hero full-bleed sobre : fond navy ou blanc cassé, Mark + `ELFIS Core`, une phrase, un CTA.  
Aucun strip de stats dans le premier viewport.  
Section Pilot = liste typographique + pastilles couleur, **pas** mosaïque d’apps.

### Login

Formulaire centré, largeur étroite, fond uni, Mark Micro en tête.  
Zéro illustration latérale.

### Launcher

Grille d’apps : Mark teinté + nom ; pastilles plates ; beaucoup d’air.  
Pas de badges promo.

### Sidebar

Étroite, fond secondary très pâle ou navy, item actif = barre 2 px + primary.  
Lockup `sidebar` ou `product-signed-h` en graisse légère.

### Topbar

Hauteur basse ; Mark 20–24 px ; search discret ; actions icon-only.

---

## 10 — Illustrations

- Style `platform_minimal` strict  
- Traits fins, 1–2 couleurs max  
- Souvent **absentes** (le vide suffit)  

---

## 11 — Icônes

Stroke unique, coins alignés DNA, taille 16/20.  
Jamais filled sauf état sélectionné contrôlé.

---

## 12 — Motion (système)

Apparition de page · micro-feedback · **pas** de séquence « connexion multi-nœuds » longue.

---

## 13 — Applications mobiles

- Densité réduite vs desktop métier  
- Tab bar neutre ; Mark favicon  
- Listes aérées ; CTA unique par écran  

---

## 14 — PDF

- Marges généreuses  
- Mark monochrome + wordmark  
- Typo dense mais aérée ; tableaux sans fond coloré saturé  

---

## 15 — Emails

- Header Mark + nom, fond blanc  
- Un CTA  
- Pas de bandeau gradient  

---

## 16 — Déclinaisons marque (sans dessiner)

### ELFIS Core

| Élément | Application DIR-A |
|---------|-------------------|
| Lockup | `mark-name-h` navy, tracking serré |
| Landing | Vide + navy ; tagline hors fichier logo |
| Shell | Platform Shell gris/navy, accent `#3D7EFF` rare |

### ComptaPilot

| Élément | Application DIR-A |
|---------|-------------------|
| Lockup | Mark vert + `ComptaPilot` ; signature `by` en graisse light |
| Shell | Vert surtout sur actif / CTA ; surfaces quasi neutres |
| Différenciation | Teinte + copy — Mark inchangé |

### SalesPilot

| Élément | Application DIR-A |
|---------|-------------------|
| Lockup | Mark bleu + `SalesPilot` ± signature |
| Shell | Bleu parcimonieux ; pipeline UI épurée |
| Risque à éviter | Trop de cartes bleues → rester Minimal |

### DocPilot

| Élément | Application DIR-A |
|---------|-------------------|
| Lockup | Mark orange + `DocPilot` ± signature |
| Shell | Orange en accent ; fonds `#FFF7ED` très dilués |
| Risque | Orange trop « marketing » → doser |

## 18 — Forces / vigilances (A seule)

**Forces :** premium immédiat · scalabilité UI · lisibilité · alignement tech.  
**Vigilances :** peut sous-exprimer l’écosystème Pilot ; Mark moins « mis en scène » ; risque de ressembler générique SaaS US.
