> **ELFIS Core n’est pas une application.**  
> **ELFIS Core est la plateforme** qui relie toutes les applications métier (les Pilot).

```
ELFIS Core
├── ComptaPilot
├── SalesPilot
├── DocPilot
├── HRPilot
├── LegalPilot
├── MarketingPilot
├── InventoryPilot
├── ProjectPilot
├── SupportPilot
└── futurs Pilot (ex. AIPilot)
```

## Décisions B0.5

1. Émotions (ordre) : Confiance → Intelligence → Fluidité → Connexion → Performance → Simplicité → Modernité → Premium.  
2. Style illu : **elfis_connected_minimal** ; interdiction stock clichés.  
3. Motion = circulation Cross-Pilot ; Mark stable.  
4. Pack produit obligatoire : Hero, Mockup, Illustration, Phrase, Bénéfice, Couleur, Icône, CTA, Capture.  
5. Brief image prêt pour B0.6.  
6. Aucun asset graphique produit.
