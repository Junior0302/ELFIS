# 22 — Illustration Language & Icon Language

**Phase :** B0.5  
**Direction :** Connected Ecosystem  
**Style système :** **`elfis_connected_minimal`**  
**Portée :** règles — **aucune image produite**.

---

## 1 — Illustration Language

### Style global

| Dimension | Décision |
|-----------|----------|
| Dominant | **Minimal flat géométrique** + traits fins |
| 3D réaliste / plastic | Interdit |
| Isométrique | Parcimonie (1 scène archi écosystème max) |
| Wireframe UI | Autorisé (expliquer flux / shell) |
| Glass illustré / blobs / mesh | Interdit |
| Hand-drawn rough / collage sticker | Interdit |
| Photo stock comme « illustration » | Interdit (voir interdits imagery) |

### Personnages

- Silhouettes géométriques, proportions sobres, diversité sans caricature  
- Groupes 2–4 (collaboration)  
- **Interdit :** mascottes, robots IA, super-héros, cartoon enfantin  

### Bureaux & entreprises

- Espaces contemporains ordonnés, salles de pilotage, multi-écrans  
- **Interdit :** babyfoot startup, open space chaos, logos concurrents  

### Dashboards & mockups

- Shell ELFIS reconnaissable (sidebar, topbar, Mark)  
- Primary = Pilot actif ; données abstraites lisibles  
- **Interdit :** UI glitter illisible, faux logos dans le chrome  

### Appareils

- Laptop / desktop / mobile sobres, angles DNA, écrans montrant UI ELFIS  
- Peu ou pas de reflets chrome agressifs  

### Scènes

- Connexion entre métiers, famille Pilot, circulation abstraite de données  
- Mark peut apparaître **comme objet** — jamais déformé  
- **Interdit :** réseau neuron neon, second symbole métier  

### Interdits imagery (photo & illu)

| Interdit absolu |
|-----------------|
| Banques d’images génériques comme identité |
| Homme / femme seul devant un graphique qui monte |
| Poignée de main isolée cliché |
| Photos corporate datées (poignée + skyline + smile forcé) |
| Confettis, neon party, crypto aesthetic |

## 2 — Icon Language

| Paramètre | Valeur |
|-----------|--------|
| **Taille maître** | 24×24 (live area 20×20) |
| **Épaisseur** | 1,5–2 px @ 24 (scaler proportionnel) |
| **Coins / rayons** | Alignés DNA UI — adoucis, pas pill |
| **Grille** | Keylines centrés ; alignement optique |
| **Style** | Line / stroke ; fill ≤ 40 % si état |
| **Perspective** | 2D frontale (pas d’iso dans l’UI) |
| **Ombre sur icône** | Interdite |
| **Couleur** | `currentColor` ; primary seulement actif / accent |
| **Cohérence** | Une famille Platform + tous Product Shells |
| **Hover** | Opacité / stroke léger — pas de bounce |
| **Transition** | 120–180 ms ease-out |
| **Animation** | Rare ; pas de boucle décorative |
| **Règle logo** | Icône métier ≠ Pilot Mark |

Emoji : jamais en navigation primaire.
