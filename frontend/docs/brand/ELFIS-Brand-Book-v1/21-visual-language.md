# 21 — Visual Language (Visual Identity System)

**Phase :** B0.5 — ELFIS Visual Language  
**Direction officielle :** **Connected Ecosystem** ([20](./20-brand-recommendation.md))  
**Horizon :** guider produit, marketing, logos, UI, print, vidéo — **10 ans**  
**Portée :** documentation uniquement — **aucun SVG, PNG, image, code, composant**.

Complète B0.1–B0.4 sans contradiction (Pilot Mark unique, palette, lockups, DIR-B + greffons A/C).

---

## 1 — Brand Emotions

Ordre officiel d’intensité (du plus structurant au plus expressif) :

| Rang | Émotion | Comment elle apparaît visuellement |
|------|---------|-------------------------------------|
| 1 | **Confiance** | Navy dominant sur Master Brand ; contrastes WCAG ; typo stable ; ombres légères ; pas de gadget ; PDF/emails sobres |
| 2 | **Intelligence** | Hiérarchie claire ; densités ordonnées ; dashboards lisibles ; absence de clutter ; Mark géométrique précis |
| 3 | **Fluidité** | Espaces réguliers ; motion court ease-out ; navigation sans rupture ; switch Pilot = Mark stable |
| 4 | **Connexion** | Mark mis en scène ; launcher famille ; filets/liens abstraits ; pastilles Pilot cohérentes ; signature `by ELFIS Core` |
| 5 | **Performance** | Métriques nettes ; tableaux ordonnés ; CTA uniques ; graphiques primary Pilot ; zéro ornement inutile |
| 6 | **Simplicité** | Une intention / viewport ; moins mais mieux ; formulaires aérés hors tables métier |
| 7 | **Modernité** | Flat géométrique ; grille 8 ; interfaces respirantes ; pas de clichés corporate 2010 |
| 8 | **Premium** | Matériaux mats ; dégradés subtils ; grain faible ; goodies monochromes ; jamais bling / neon |

**Jamais évoquer :** jouet, glow crypto, « compta only », mascotte, chaos multi-symboles, startup brouillonne.

## 2 — Visual Language (paramètres)

| Paramètre | Règle ELFIS | Sensation |
|-----------|-------------|-----------|
| **Formes** | Rectangles, rares cercles (avatar/état), Mark sur grille 8×8 | Ordre, outil |
| **Lignes** | Filets 1 px neutres ; stroke Mark / icônes cohérents | Précision |
| **Angles** | Famille unique de rayons moyens (DNA) — pas sharp brutal ni pill systématique | Soft enterprise |
| **Courbes** | Limitées au Mark + rayons UI ; pas de blobs organiques | Contrôle |
| **Espaces** | Grille 8 ; public = air (A) ; workspace = densité maîtrisée | Respiration / focus |
| **Contrastes** | Texte fort / surfaces adjacentes douces | Lisibilité premium |
| **Densité** | Marketing basse ; métier variable mais alignée | Clarté contextuelle |
| **Rythme** | Sections 1 job ; stagger motion 30–50 ms max | Cadence calme |
| **Équilibre** | Un focal (Mark ou headline) ; asymétrie contrôlée OK | Stabilité |
| **Profondeur** | 2–3 plans ; élévation discrète | Suite logicielle |
| **Transparence** | Overlays / modales seulement | Focus modal |
| **Grain** | Noise 2–4 % max | Matière print/web |
| **Halo** | Radial soft derrière Mark (splash) | Ancrage symbole |
| **Blur** | Backdrop overlays — pas glass partout | Hiérarchie spatiale |

## 5 — Typographic Expression

Une **famille wordmark** pour toute la suite (figée au tracé ; logique déjà B0.3).

| Usage | Expression |
|-------|------------|
| **ELFIS Core** | Deux mots, espace mot, graisse primary wordmark, navy ; jamais `Elfis` / `ELFISCORE` |
| **ComptaPilot / SalesPilot / …** | CamelCase exact ; même tracking entre Pilot ; Mark → gap 0,5–0,75 H |
| **Titres** | Fort contraste ; une ligne d’impact préférée ; pas de titre qui écrase le brand sur hero |
| **Sous-titres** | Graisse intermediate ; couleur neutre foncé |
| **Paragraphes** | Corps lisible ; interligne généreux marketing ; plus compact métier |
| **Métriques** | Tabular nums si possible ; graisse semibold ; primary ou navy — pas arc-en-ciel |
| **Marketing** | Phrases courtes ; promesse plateforme d’abord |
| **PDF** | Hiérarchie stricte ; Mark Micro en tête ; pieds `by ELFIS Core` (Pilot) |
| **Slides** | 1 idée / slide ; titres courts ; Mark coin cohérent |

Signature `by ELFIS Core` : graisse plus légère ; italique optionnel **uniquement** ici.

## 7 — Moodboard textuel (détaillé)

**Matières :** acier brossé mat, verre clair non miroir, papier mat premium, soft-touch anthracite, tissu chine gris-bleu — pas chrome, pas paillettes.

**Couleurs :** navy comme socle ; secondary lavées comme air ; primary Pilot comme **signal** ponctuel (jamais papier peint).

**Lumière :** nord doux, highlights froids, ombres diffuses ; splash = halo soft derrière Mark.

**Profondeur :** fond → contenu → Mark/CTA ; blur réservé overlays.

**Contraste :** texte/fond fort ; cartes/fond faible ; métriques détachées par graisse.

**Composition :** grille, un focal, asymétrie 60/40 acceptable ; hero sans cards.

**Ambiance :** suite d’expertises reliées ; calme opérationnel ; ambition sans agressivité ; premium européen B2B.

**Émotions dominantes :** confiance → intelligence → fluidité → connexion (dans cet ordre de lecture).
