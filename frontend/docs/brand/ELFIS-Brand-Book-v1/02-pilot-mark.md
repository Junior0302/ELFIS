# 02 — Pilot Mark

## Définition officielle

Le symbole actuellement utilisé dans l’écosystème devient le **Pilot Mark**.

Ce n’est **plus** le logo exclusif de ComptaPilot.

C’est désormais le **symbole mère** de tout l’écosystème ELFIS.

> **Pilot Mark** = signe partagé de la famille de produits.  
> **Logos produit** = déclinaisons du Pilot Mark + identité nominale du Pilot (système en [B0.2](./10-symbol-system.md) ; tracé en **B0.3**).

---

## Pourquoi

1. **Unité** — un seul signe reconnaissable pour toute la plateforme.
2. **Famille** — chaque Pilot hérite du même ADN symbolique.
3. **Indépendance** — ComptaPilot ne « possède » plus le symbole ; ELFIS Core en est le gardien.
4. **Évolutivité** — les futurs Pilot s’ajoutent sans inventer un symbole incompatible.

---

## Comment (règles conceptuelles — sans dessin)

Le Pilot Mark doit :

- être reconnaissable en très petite taille (favicon, App Launcher, avatar) ;
- fonctionner en monochrome et en couleur produit ;
- supporter une zone de protection claire ;
- pouvoir s’associer à un wordmark (`ELFIS Core`, `ComptaPilot`, etc.) ;
- rester stable dans le temps (pas de redessin à chaque Pilot).

Le Pilot Mark **ne doit pas** :

- contenir le nom d’un produit dans le glyphe ;
- être redessiné librement par produit ;
- être remplacé par une icône métier (calculatrice, graphique, etc.) comme symbole mère ;
- être confondu avec le logo final d’un seul Pilot.

---

## Variantes autorisées (concept)

| Variante | Usage |
|----------|--------|
| **Mark seul** | Favicon, launcher mark, avatar compact |
| **Mark + wordmark plateforme** | Surfaces ELFIS Core (landing, login, Platform Shell) |
| **Mark + wordmark produit** | Product Shell, marketing Pilot |
| **Mark monochrome clair** | Sur fonds sombres / primary produit |
| **Mark monochrome foncé** | Sur fonds clairs / documents imprimés |
| **Mark teinté produit** | Accent Pilot (vert Compta, bleu Sales, etc.) — le glyphe reste identique |

---

## Déclinaisons produit (principe)

Chaque Pilot pourra utiliser :

1. le **Pilot Mark** (glyphe commun) ;
2. éventuellement une **teinte** selon la palette produit ;
3. un **lockup** : Mark + nom du Pilot (+ optionnellement `by ELFIS Core`).

Aucun Pilot ne crée un symbole concurrent du Pilot Mark.

---

## Interdictions

- Modifier les proportions du Mark.
- Ajouter des effets (ombre portée marketing, dégradés non validés, outlines multiples).
- Placer le Mark dans une forme concurrente (hexagone, badge promo) sans validation Brand.
- Utiliser le Mark ComptaPilot « historique » comme propriété exclusive de ComptaPilot dans la communication plateforme.
- Animer le Mark de façon à le déformer (squash, morphing vers une autre icône).
