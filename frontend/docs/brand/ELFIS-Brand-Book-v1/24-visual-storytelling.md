# 24 — Visual Storytelling

**Phase :** B0.5  
**Direction :** Connected Ecosystem  
**Rôle :** histoires visuelles officielles pour marketing, produit, vidéo, slides.

---

## 1 — Arc narratif maître

> **Une entreprise qui pilote plusieurs expertises sur une seule plateforme.**  
> Les données circulent. Les Pilot collaborent. La vision devient décision. La décision nourrit la croissance.

Personnage implicite : l’organisation (pas un « hero founder » cliché).  
Symbole constant : **Pilot Mark** = connexion.

---

## 2 — Histoires autorisées (chapitres)

| Histoire | Visuel type | Émotions touchées |
|----------|-------------|-------------------|
| **Entreprise qui grandit** | Échelle : 1 équipe → multi-métiers ; grille Pilot qui s’étend | Confiance, croissance |
| **Données qui circulent** | Filets / flux abstraits entre modules ; Mark stable | Fluidité, intelligence |
| **Applications qui collaborent** | Launcher, pastilles teintes, switch Compta↔Sales Mark fixe | Connexion |
| **Vision globale** | Platform Shell, vue transverse, navy | Confiance, intelligence |
| **Décision** | KPI clair, CTA unique, validation success système | Performance, simplicité |
| **Croissance** | Pipeline / jalons / tendances — sans rocket sticker | Performance, modernité |

Ordre de récit landing recommandé :

1. Promesse plateforme  
2. Connexion / Mark  
3. Famille Pilot  
4. Preuve produit (mockups)  
5. Décision / CTA  

---

## 3 — Histoires interdites

- Sauveur individuel devant un chart vert  
- « Disruption » agressive / confetti  
- Guerre des outils / bash concurrents visuel  
- IA anthropomorphe qui « remplace » les équipes  
- Compta isolée comme identité ELFIS  

---

## 4 — Storytelling par marque

| Marque | Récit focal | Toujours rappeler |
|--------|-------------|-------------------|
| **ELFIS Core** | Socle qui relie | Une plateforme. Plusieurs expertises. |
| **ComptaPilot** | Fiabiliser la finance **dans** la suite | `by ELFIS Core` |
| **SalesPilot** | Pipeline relié au reste de l’entreprise | Mark stable au switch |
| **DocPilot** | Documents comme nœud de circulation | Pas de picto doc dans le Mark |
| Futurs Pilot | Nouvelle pastille, même histoire famille | Checklist [15](./15-brand-consistency-checklist.md) |

---

## 5 — Formats de récit

| Format | Structure |
|--------|-----------|
| Landing | Hero promesse → écosystème → Pilot → preuve → CTA |
| Vidéo 30–60 s | Mark → connexion pastilles → 1 mockup Pilot → CTA |
| Carrousel LinkedIn | Problème fragmenté → plateforme → bénéfice |
| Slide board | Situation → complication (silos) → résolution ELFIS → Pilot |
| Empty state produit | Situation → action CTA (micro-histoire) |

---

## 6 — Cohérence 10 ans

Chaque nouvelle campagne doit pouvoir se résumer ainsi :

1. Quelle **histoire** (tableau §2) ?  
2. Quel **Pilot** / Core ?  
3. Le Mark est-il **inchangé** ?  
4. Les émotions respectent-elles l’ordre [21](./21-visual-language.md) §1 ?  

Si non → hors Brand.
