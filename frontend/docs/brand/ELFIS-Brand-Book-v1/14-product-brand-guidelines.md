# 14 — Product Brand Guidelines

**Phase :** B0.3  
**Rôle :** fiches standard + règles d’héritage pour chaque Pilot.  
Complète [04 — Personnalité](./04-personnalite-des-produits.md) et [13 — Logo Architecture](./13-logo-architecture.md).

---

## Fiche standard (template)

Chaque Pilot dispose d’une fiche au format suivant.  
Les champs **Logo / Illustration / Iconographie / Motion** décrivent des **règles**, pas des fichiers livrés en B0.3.

```
Nom officiel
Mission
Promesse
Public
Couleur primary / secondary / accent
Émotion / mots-clés
Logo (héritage + specificités lockup)
Illustration (style autorisé)
Iconographie
Univers (shell, photo, tone)
Motion (motifs autorisés)
```

## Synthèse héritage vs propre

```
PARTAGÉ                          PROPRE AU PILOT
─────────────────────────────    ─────────────────────────
Pilot Mark                       Wordmark
Grille / DNA / Motion system     Primary / accent
Wordmark System (logique)        Émotion & copy
Signature « by ELFIS Core »      Shell métier / illustrations
Checklist cohérence              Iconographie d’état (couleur)
```
