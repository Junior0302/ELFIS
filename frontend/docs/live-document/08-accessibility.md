# 08 — Accessibility

| Zone | ARIA |
|------|------|
| Autosave / statut | `role="status"` `aria-live="polite"` `aria-atomic` |
| Totaux | `aria-live="polite"` sur `LiveTotals` |
| Insights | `aria-live="polite"` `aria-relevant="additions"` |
| Preview zoom | `aria-live` sur label % |
| Contrôles preview | `role="group"` + `aria-pressed` |
| Page PDF | `aria-label` sur input |
| Reduced motion | flash totaux / scale désactivés |

Pickers : comportements clavier Smart Search inchangés (P1.0).
