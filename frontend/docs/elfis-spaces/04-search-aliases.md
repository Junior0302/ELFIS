# 04 — Recherche et alias

## Champ

Placeholder : **Rechercher un espace, une fonction…**

## Cible

Sans connaître ComptaPilot / SalesPilot : l’utilisateur cherche *facture*, *TVA*, *pipeline*, *congés*, etc.

## Haystack

- Titre / description espace
- Capabilities
- `searchAliases` (catalogue)
- Labels + `to` des raccourcis
- Signature moteur (optionnel, secondaire)
- Route d’entrée
